# Experimental Design

The Hall Effect Sensor array is going to be used as a magnetic camera during DIC experiments. This allows for live monitoring of constant or variable magnetic fields. The set-up must be designed in such a way that the DIC still has total visual access to the test sample, but the magnetic field measurements are still accurate. 

To start with, the magnetic field recording will be done without the test sample in place. Instead of having a live-feed of the field, it will be pre-recorded. This allows for the sensor array to be in the exact place that the test sample would be in during the experiment and obviously the same fields would be produced. 

The hardware used to hold the array in place and know where the measurements are being taken from is being designed on CAD software and will be 3D-printed. 

The idea is to have a stage that can move the array forwards and backwards in the magnetic field and take measurements at each increment. This will allow for a complete picture of the field in 1 dimension. To get different components of the field aside from the field values perpendicular to the test specimen, the array will have to be rotated to get the other 2 axes of fields.

A rotation stage will have to be designed/incorporated into this to accommodate the different components on the field.
