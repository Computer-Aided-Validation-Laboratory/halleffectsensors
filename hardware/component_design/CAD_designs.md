# CAD Component designs

The initial sensor array calibration was done using the 1 dimensional calibration software, this was done just in a breadboard, however for larger sensor arrays and for 3 dimensional calibration, some hardware will be needed to house the sensor array. The initial idea is to use a cube so that you can easily have sensors pointing in all three directions, out of each face:

<img width="405" height="485" alt="image" src="https://github.com/user-attachments/assets/60daaf4c-101b-45a9-b1c6-6bcf4710b8ba" />

The other option is to use the FUJUKEN coils with the new 16-bit resolution ADC and have a cuboid setup going across the sample holder setup in the coils to measure the field in 3 directions.   
(Design for this has not yet been completed)

The current plan for an extended sensor array (before the PCB has been completed) is to use a kind of shelf design that will have holders for sensors in 3 directions (basically a clunkier version of what the PCB will be).
