# Development of a Modular Hall Effect Sensor Array for Magnetic Field Mapping of Helmholtz Coils 
--------------------------------------------------------------------------------------------------------------------------------------
## Project Summary 

This placement project will deliver a laboratory-ready magnetic field mapping system based on a distributed array of Hall effect sensors. The student will design, build and validate a hardware and software platform capable of measuring magnetic fields generated by a variety of Helmholtz coil configurations. 

The developed sensor array will be integrated within an existing image-based diagnostics suite, enabling synchronised measurements using the MatchID digital image correlation (DIC) software and National Instruments (NI) data acquisition hardware. This capability will support the generation of high-quality benchmark datasets for electromagnetic validation studies. 

The project provides a unique opportunity to gain multidisciplinary experience spanning electronics, embedded systems, uncertainty quantification (UQ), Python software development, computer-aided design (CAD), additive manufacturing, experimental diagnostics, and data analysis. 

--------------------------------------------------------------------------------------------------------------------------------------
## Background and Motivation 

Helmholtz coils are widely used in scientific and engineering applications to generate well-characterised magnetic fields for calibration, validation, and research activities. Accurate characterisation of magnetic field distributions is essential when developing and validating electromagnetic models and experimental measurement techniques. 

Traditional magnetic field mapping is often performed using single-point Hall probes, requiring manual positioning throughout the measurement volume. Such approaches can be time-consuming, susceptible to positioning errors, and difficult to scale for high-resolution measurements. Furthermore, many commercially available magnetic field measurement systems are relatively expensive and may have limitations regarding the maximum measurable magnetic field strength, sampling rates, or integration with existing experimental infrastructure. 

The development of a low-cost, modular, and scalable Hall effect sensor array presents an opportunity to rapidly acquire spatially resolved magnetic field measurements while generating benchmark datasets that can support electromagnetic validation and uncertainty quantification activities. 

--------------------------------------------------------------------------------------------------------------------------------------
## Project Objectives 

* Design and construct an array of Hall effect sensors for magnetic field strength measurements. 

* Develop an Arduino-based data acquisition system for sensor interrogation and data collection. 

* Develop Python software for data acquisition, logging, processing, visualisation, and analysis. 

* Design and manufacture sensor support structures using CAD software and in-house 3D printing facilities. 

* Integrate the sensor array with the MatchID data acquisition and image-based diagnostics platform. 

* Develop calibration methodologies and assess measurement uncertainties. 

* Generate magnetic field maps for multiple Helmholtz coil configurations. 

* Produce complete technical documentation, operating procedures, and user guidance.

## Expected Deliverables 

By the end of the project the expected deliverables are as follows: 

* A validated Hall effect sensor array for magnetic field measurements. 

* Arduino firmware repository and associated documentation. 

* Python software package for data acquisition and analysis. 

* CAD models and STL files for all manufactured components. 

* Sensor calibration procedures and uncertainty assessment documentation. 

* Magnetic field mapping datasets for multiple Helmholtz coil configurations. 

* Integration of the sensing platform with the MatchID data acquisition system.
